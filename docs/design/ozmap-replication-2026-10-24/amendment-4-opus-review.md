# Amendment 4: Opus B review (2026-10-24)

Model claude-opus-5-5, fresh subagent, read only, blind to bench/ozmap_rep/. Verdict: sign conditional on B4.1, B4.2 and B4.4.

**B4.1 BLOCKER (A4.2, tool execution).** On 0.160.0 tools cannot be fully switched off. `codex --disable shell_tool --disable unified_exec features list` reports shell_tool false but unified_exec still true; `-c features.unified_exec=false` gives the same result. As written, no call could launch. Replacement: "The frozen arguments disable every tool feature the pinned CLI allows to be disabled. Before each wave, the driver records the effective state from `codex features list`, run with the same CODEX_HOME and arguments. A feature that stays enabled (observed: unified_exec) is recorded and does not block launch. Tool events are then handled only under A4.3. Read-only sandbox, an empty working directory and a clean home keep a tool call unlikely; they do not excuse one."

**B4.2 BLOCKER (A4.2, authentication).** auth.json holds a ChatGPT refresh token. Rebuilding worker homes from one baseline can reuse a rotated token and revoke the session family, the owner's own login included. Replacement: "Refresh authentication once in the baseline home before each wave. After every call, compare the worker auth.json hash with the baseline; if it changed, copy it back to the baseline under a lock before the next reconstruction, and log hashes only. Telemetry calls must show that the pinned CLI reads authentication from the CODEX_HOME file and not an OS credential store, and that the read-only sandbox starts in a clean home (sandbox state lives in CODEX_HOME on this machine). If either check fails, stop before evaluation."

**B4.3 CHANGE (A4.2, arguments).** Name the flags: "`exec --ignore-user-config --ignore-rules --ephemeral --skip-git-repo-check --json -s read-only -C <numbered empty dir>`, plus every available `--disable` for plugins, apps, memories, hooks, multi_agent, skill_search, browser_use, computer_use, image_generation and view_image, plus `-c project_doc_max_bytes=0` if accepted."

**B4.4 BLOCKER (A4.6, classification).** Declaring all four materials ops rule shaped contradicts A4.6's own independent classification, and the ops author was told to make at least one op awkward. Sonnet also makes ordinary materials errors (252/256 pilot warm A), so it could invalidate the run without learning anything. Replacement: "Delete 'The four eligible materials operations are rule shaped.' Let R be the set of materials ops classified as rule shaped. A bootstrap gold error or matched A disagreement invalidates efficiency only on an op in R for which the learner proposed a rule. Every other bootstrap error counts in correctness and overhead. A4.10 gates are evaluated on the whole workload as preregistered and also reported per op. An op outside R is expected to stay model answered; that is not a failure. A rule admitted for an op outside R is a classification miss; safety rules still apply. The A4.11 magnitude is computed on jobs of ops in R. If R is empty, materials efficiency is descriptive and no rule learning claim is made."
